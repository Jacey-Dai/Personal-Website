# Updating content

Edit src/content.js. Keep stable place IDs because they are public links. `name` is the imaginative place name; `label` is the standard navigation category. Sections currently hold explicit placeholders, not biographical facts.

Before publishing personal content, supply:

1. Preferred public name, one-line positioning, short About, primary language.
2. Two or three real projects: problem, role and team, methods, decisions, evidence, links.
3. Verified education/work records and dates.
4. Real community, leadership, volunteering or interest stories.
5. Short Currently updates with dates.
6. Resume PDF and verified email/social URLs.

Do not replace missing metrics with plausible numbers. Publish only approved public information. Add resume links only when the actual file exists; use the Vite base URL when linking assets under public/. Current utility pages explain missing content rather than presenting broken links.
